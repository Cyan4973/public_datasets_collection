# zenodo_wallhack18k_esp32_wifi_csi_i8

- Date: 2026-10-09
- Status: blocked
- Candidate dataset: Wallhack1.8k (TU Wien; Strohmayer, Julian and Kampel, Martin), raw ESP32-S3 Wi-Fi CSI per-packet int8 imaginary/real subcarrier pairs (LLTF + HT-LTF, 128 subcarriers, len=256, 100 Hz), 44 recording CSVs in {LOS, NLOS} x {BQ, PIFA}
- Source: https://zenodo.org/records/13950918 (DOI 10.5281/zenodo.13950918, version 1.0.1, published 2024-10-18); bulk file https://zenodo.org/api/records/13950918/files/wallhack1.8k.zip/content (135,133,863 bytes, md5 57a0b9baa3532e1172b25d756536071a)
- Why it looked promising: a new modality for the int8 corpus (commodity Wi-Fi channel state information, i.e. frequency-domain channel estimates). The source stores native signed int8. There are 44 natural recording files, about 180M values in total, all from one chip, one firmware CSI format and one packet rate. A single small download.
- Failure class: license conflict / rights ambiguity
- What happened: the Zenodo API metadata declares `"license": {"id": "cc-by-4.0"}`. The authors' description on the same record has a "Download and Use" section that states: "This data may be used for non-commercial research purposes only. If you publish material based on this data, we request that you include a reference to one of our papers [1,2]." The companion GitHub repo StrohmayerJ/wallhack1.8k has no license (GitHub API `license: null`), and neither its readme.md nor the readme.txt inside the zip clarifies the terms. This mirrors the deepmind_alphamissense_substitution_scores_f32 precedent: a CC BY 4.0 statement contradicted by a non-commercial notice on the exact data object, which was blocked rather than resolved in favour of the permissive reading.
- Evidence: Zenodo API JSON https://zenodo.org/api/records/13950918, fetched 2026-10-09 (metadata.license and metadata.description "Download and Use" paragraph). A tail range-GET of the zip parsed its central directory: 1,894 entries, of which 44 are raw CSI CSVs (LOS/NLOS x BQ/PIFA x b1, w1-5, ww1-5; 9.7-51.3 MB uncompressed). The rest are spectrograms/*.png, label CSVs, meanStd.csv and readme.txt. readme.txt (2,622 bytes) was inflated and carries no license text.
- Logs: probe scratch under /tmp/autocollect/zenodo_wallhack18k_esp32_wifi_csi_i8/ (record.json, tail.bin, cd.py). No bulk download and no staging recipe.
- Decision: blocked. No recipe was authored and no bulk payload was fetched. The rights evidence for the exact data object is internally contradictory (CC BY 4.0 metadata vs a non-commercial-only usage statement by the authors).
- Retry conditions: retry only if the authors (Strohmayer/Kampel, TU Wien CVL) remove or clarify the "non-commercial research purposes only" statement on Zenodo record 13950918 (or a new version), or publish an explicit statement that CC BY 4.0 governs wallhack1.8k.zip without additional use restrictions. Technically the recipe is ready to write: one pinned zip, stdlib zipfile + csv, keep rows with type==CSI_DATA and len==256, and emit one int8 sample per CSV.
