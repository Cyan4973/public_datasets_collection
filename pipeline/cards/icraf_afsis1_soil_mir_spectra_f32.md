- Risks: (1) Width: the text has up to 8 significant digits. These look like 4-replicate averages of 6-decimal values (last two digits cluster on 25/75/x5). Nearest-float32 rounding has max relative error 6.0e-8 and was injective on the probe file (506,982 distinct texts became 506,982 distinct f32), but about 46% of values do not reproduce their last printed digit. The judge may prefer f64. The counter-argument is that Bruker OPUS stores float32 natively and f64 would widen averaged f32 data. (2) The OSSL docs list the AfSIS1 instrument as 'Tensor 27 FT-IR & Alpha I ZnSe'. The builder must check that all 19 files share the identical header grid and reject or split any file that does not. (3) Dataverse ignores Range (it returns a full 200 body) and the first request once stalled to a timeout before a retry succeeded. download.sh needs --retry, and resume via -C - will not work; files are at most 37 MB. (4) About 18k small samples (about 7 KB each); each passes the 1,000-value median floor (1,749). (5) The dataset is version 1.1 (released 2025-06-19); pin the MD5s and sizes from the API listing.
