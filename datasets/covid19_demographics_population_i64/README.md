# COVID-19 Demographics Population Int64
Domain: global demographics population counts (total, male, female, age brackets) from COVID-19 Open Data, int64. Distinct from US census ACS PUMS (California person microdata) — global scope, different source (World Bank/UN via COVID open data).
Source: https://storage.googleapis.com/covid19-open-data/v3/demographics.csv (GCS allowlisted, 1.5MB, verified 200).
Build: 6 samples, 108k values, median 17k, passes floor.
