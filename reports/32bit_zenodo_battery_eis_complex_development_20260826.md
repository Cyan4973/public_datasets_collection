# Zenodo Battery Complex EIS Histories Float32 — 2026-08-26

## Outcome

Accepted `zenodo_battery_eis_complex_f32`: 26 variable-length battery-cell
histories containing 4,297 complex electrochemical-impedance spectroscopy
experiments.

The recipe contributes 524,234 float32 values and 2,096,936 primary bytes.
Each natural sample is one complete cell history shaped
`[experiment, frequency=61, complex_component=2]`; sample sizes range from
14,152 to 193,248 bytes.

## New domain and shape

This is the first accepted electrochemical-impedance family. The committed
corpus and attempt registry contain no previous EIS or complex frequency-
response dataset. Unlike scalar spectra, ordinary sensor timelines, or image
planes, each experiment is a paired real/imaginary response across a
logarithmic frequency axis. Repeated experiments within each cell then form an
ageing history over cycle and state-of-charge conditions.

Rows are grouped only at the source's natural `Cell_ID` boundaries. The source
already stores all rows for each cell contiguously and in nondecreasing cycle
order. It exposes 26 cell blocks with 29 to 396 experiments each; all resulting
payloads are nonconstant and byte-distinct.

## Source, rights, and representation

Zenodo record `17792537` is the METAS-processed “LiBforSecUse processed data
for machine learning modelling and uncertainty propagation” release. The
record explicitly declares CC BY 4.0 and identifies its original CC BY 4.0
source as LiBforSecUse V2, Zenodo record `6418665`. The manifest preserves the
requested attribution to both releases.

The selected 8,139,517-byte text table is pinned by MD5 and SHA-256. It contains
4,297 unique experiment IDs from 26 commercial 18650 cells and 122 EIS columns:
paired `Z_real` and `Z_imag` values at 61 log-spaced frequencies from `10^-2`
through `10^4` Hz. The authors created this aligned grid with cubic-spline
interpolation; the recipe performs no interpolation of its own.

Because the source is decimal text, the representation is classified as
derived operational float32. Each finite impedance value is parsed and rounded
once to IEEE-754 binary32, then serialized little-endian in
`[experiment, frequency, real/imaginary]` order.

## Missing values

The processed source leaves real/imaginary pairs blank wherever frequency-grid
alignment would require extrapolation. The recipe preserves the rectangular
shape and converts the 1,354 blank component positions to the canonical
little-endian float32 quiet-NaN word `0x7fc00000`. It rejects unpaired blanks,
explicit non-finite text, and infinities rather than silently changing source
semantics.

## Verification

Verification pins the record and table identities, CC BY 4.0 declaration,
exact 134-column schema, 61-frequency grid, 4,297 unique experiment IDs, cell
block order and sizes, monotonic cycle order, paired missingness, per-cell
output hashes, aggregate converted hash, and finite/NaN totals. It reparses the
source and compares every generated byte, the index, the statistics document,
and the exact set of output files.
