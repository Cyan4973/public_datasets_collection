# NOAA/NSIDC Climate Data Record Sea-Ice Concentration (G02202 v4) Northern-Hemisphere Daily Grids UInt8

- Candidate id: `noaa_cdr_seaice_conc_nh_daily_u8`
- Width: uint8
- Quantity: CDR passive-microwave sea-ice concentration, variable cdr_seaice_conc, uint8. Codes 0-100 are percent concentration (scale 0.01 to fraction). Flag codes 251-255 mark pole hole, lake, coast, land and missing. Grid is 304x448 at 25 km on the NSIDC polar stereographic north projection, one map per day.

- Decode path: NetCDF4/HDF5 decoded with the stdlib only. Superblock v0, but the root group and variables use v2 object headers (OHDR/OCHK) with dense link storage. Steps: root OHDR, then Link Info message, then fractal heap (FRHP) direct block, then Link messages giving name and object-header address. Select 'cdr_seaice_conc' by name, not position: the probe found 9 uint8 variables with an identical layout. In the variable OHDR: Dataspace (1,448,304), Datatype class 0 size 1 unsigned, Filter pipeline deflate only, Layout v3 chunked with a single chunk (1,448,304) indexed by a v1 B-tree (TREE). Read the chunk address and size from the B-tree leaf, zlib.decompress, and check the length is 136,192. Use the long_name/flag_values attributes as validation. Per-file .mnf checksum manifests exist under data/final/north/checksums/.

The local noaa_ims_snow_ice_cover_u8 is a different product (categorical 0-4 IMS snow/ice classes), not a percent concentration.
- Homogeneity: One hemisphere (north, fixed 304x448 grid), one variable (cdr_seaice_conc), one algorithm version (v04r00), one sensor (F17 for all 365/365/366 files of 2022, 2023 and 2024), so the pole-hole footprint is constant. Do not mix the south grid (316x332), monthly means, or the goddard_*/nsidc_* intermediate estimates.
- Risks: The main risk is the builder having to implement HDF5 v2 object headers and fractal-heap link lookup in pure Python (needs_tooling if that fails). Accepted precedents decode HDF5 v0 chunked-deflate and NetCDF4 contiguous datasets. Flag codes 251-255 sit inside the same raster as concentrations and must be documented as native codes, not missing. Daily maps are fairly smooth and summer-winter correlated (fine). Yearly aggregate files (~54 MB, 365 days) are an alternative natural container, but the daily file is the natural record.
- Probe evidence: Bucket noaa-cdr-sea-ice-concentration-pds lists anonymously: data/final/{north,south}/{daily,monthly,aggregate,checksums}. 2022/2023/2024 north daily have 365/365/366 files totalling 84.9/87.0/86.4 MB, all f17_v04r00. A 32 KB header range read of seaice_conc_daily_nh_20200101_f17_v04r00.nc showed superblock v0, root OHDR with a Link Info message, FRHP/BTHD dense storage, and 9 u8 datasets with DSPACE (1,448,304), DTYPE '10000000 01000000' (unsigned 1-byte), FILTER deflate, and LAYOUT v3 chunked with single chunk dims (1,448,304,1) behind v1 B-tree addresses.
