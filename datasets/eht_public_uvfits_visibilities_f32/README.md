# EHT Public UVFITS Visibilities Float32

This recipe uses the official Event Horizon Telescope GitHub
organization for calibrated UVFITS visibility data published with an explicit
permissive license. UVFITS stores measurements in the spatial-frequency plane,
not reconstructed image pixels.

The intended OpenZL representation separates each numeric field into an aligned
homogeneous series:

- real visibility float32;
- imaginary visibility float32;
- visibility weight float32.

No output will interleave these fields. The selected Stokes-I files store
byte-identical RR and LL copies in every random group; the recipe validates
that equality and emits one copy rather than artificially doubling the data.
RL/LR placeholders are accepted only when their real and imaginary components
are zero and their weights are zero or positive infinity, then excluded. FITS
big-endian words are byte-swapped to canonical little-endian float32 without
changing their bit patterns. Magnitude/phase conversion, normalization,
imaging, gridding, interpolation, and concatenation are excluded.

This would add a new numerical structure: sparse complex interferometric
measurements indexed by telescope baseline, time, frequency, and polarization.
Existing astronomical families contain image planes, light curves,
detector-event channels, or raw radio I/Q samples, but no calibrated
cross-telescope visibilities in the Fourier plane.

The accepted recipe emits fifteen samples: one real, imaginary, and weight
series for each of five observations. Each field contains 58,813 values across
five samples (235,252 bytes); the complete family contains 176,439 primary
float32 values (705,756 bytes). Sample lengths range from 8,004 to 17,529
values, with a median of 9,744.

Run the optional license-first metadata discovery from the repository root:

```bash
bash datasets/eht_public_uvfits_visibilities_f32/discover.sh
```

The script reads GitHub repository metadata, pinned commit trees, and small
README/license documents. It does not download UVFITS payloads. Discovery found
96 direct visibility files across official releases. Their `LICENSE.txt` files
state that the data are licensed under the Open Data Commons Public Domain
Dedication and License (ODC-PDDL) 1.0.

Five HOPS-calibrated observations are selected across M87 (2017 and 2018),
3C 279, Centaurus A, and Sagittarius A*. Download and inspect those exact
commit-pinned files with:

```bash
bash datasets/eht_public_uvfits_visibilities_f32/download.sh
```

The dependency-free FITS parser validates each Git object, every data-specific
license notice, complete HDU layout, random-groups structure, float width,
Stokes layout, RR/LL equality, placeholder policy, and separate field
distributions. `build.sh` emits the samples; `verify.sh` reparses the source and
compares every generated byte and index entry.
