# MorphoDunes Laboratory PIV Float64 Vector Fields — 2026-08-26

## Outcome

Accepted `zenodo_morphodunes_piv_f64`: four paired two-dimensional laboratory
PIV velocity fields measured over fixed tidal-dune configurations.

The recipe contributes 738,020 native float64 values and 5,904,160 primary
bytes. Each natural sample is one complete `[y, x, component]` field containing
the streamwise and vertical velocity components.

## New numerical structure

This family adds dense spatial vector fields. Existing float64 families include
scalar images, time-frequency grids, molecular trajectories, tabular columns,
and irregular coordinates, but no accepted sample assigns a correlated
two-component physical vector to every cell of a rectilinear grid.

The four experiments cover ebb/flood currents, spring/neap conditions, and
low/high bed roughness. Their grids range from `146 × 617 × 2` to
`151 × 624 × 2` values.

## Source and rights

Zenodo record `16414450` explicitly declares CC BY 4.0 and documents processed
PIV fields from laboratory measurements. All four MAT files and the exact
Zenodo metadata response are pinned by size and cryptographic hash.

Inspection proved that every source variable is a native MATLAB `mxDOUBLE`
array backed by little-endian `miDOUBLE` words. This supersedes the initial
float32 hypothesis; narrowing these arrays would discard source precision.

## Representation and missing values

Each source contains matching `uPIV`, `vPIV`, `xPIV`, and `yPIV` matrices plus a
`zPIV` vector. The decoder validates the coordinate arrays as a rectilinear
grid, then interleaves each `uPIV`/`vPIV` cell in MATLAB linear order. This
yields a C-order `[y, x, component_uv]` tensor without numeric conversion.

The sources use two signed quiet-NaN bit patterns for invalid or masked PIV
vectors. These are meaningful parts of the field mask and are preserved
byte-for-byte. Across the four outputs, 549,044 values are finite measurements
and 188,976 are exact NaN words. No infinities occur.

## Verification

The dependency-free decoder checks MATLAB v5 framing, zlib streams, array
classes/types/names/shapes, coordinate-grid repetition, NaN encodings, source
identities, output hashes, and aggregate counts. Verification reparses all four
sources, reconstructs each interleaved tensor, rejects stale outputs, and
compares every generated byte.
