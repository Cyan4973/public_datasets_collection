- Natural record: One 144x144 uint8 precession diffraction pattern (20,736 values) recorded at one scan position. In the file each frame is a 6-byte marker (u16 LE 0x55AA + u32 frame index) followed by 20,736 pixels. Frames are row-major over an NX x NY scan, so one scan row of NX frames is contiguous and range-fetchable. This mirrors the accepted NORDIF EBSD recipe: kept scan rows by range request, one pattern per scan point.
