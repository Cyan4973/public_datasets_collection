- Decode path: curl range GETs. (1) Fetch the DAF file record (first 1024 B). Check 'DAF/CK ' and the 'BIG-IEEE' format, ND=2, NI=6; read FWARD. (2) Fetch the summary record at (FWARD-1)*1024. Parse NEXT/PREV/NSUM and the summaries (2 doubles + 6 ints: inst -74000, frame, type 3, av flag 1, start/end word addresses). (3) Range-GET the doubles at (start-1)*8 .. end*8 for the chosen segments. Decode big-endian with struct '>d'. Split the Type-3 layout: N records × 7 [q0..q3, av1..av3], then N epochs, then the epoch directory (floor((N-1)/100)), then interval starts and directory, then the 2-word trailer (NINTS, N). Validate that N is consistent with segment length, epochs increase strictly, and |q| ≈ 1. Write quaternions and rates as '<d' little-endian. The existing datasets/nasa_naif_de440s_spk_coefficients_f64/scripts/spk_extract.py DAF/summary logic (which already accepts BIG-IEEE) can be reused. Pure stdlib.

Weekly files total 202 GB, so the recipe must range-fetch only the selected segments and pin byte ranges and sizes.
