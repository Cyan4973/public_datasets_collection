- Natural record: One EIT recording, i.e. one EIT_rawData/<subject>_<protocol>.bin file. Emit all frames' 1024 float32 pixel values as one sample (shape T x 32 x 32). FEM recordings have 3,000-8,400 frames; PEEP_BH recordings have about 16,600-19,150 frames. Per-frame timestamps, the dummy float, the MinMax/event int32 fields, 30 event-text bytes, the timing-error int32 and the 52 Medibus floats are auxiliary at most; the Medibus floats are mostly -3.4e38 fill.
- Estimated samples: 28
- Estimated primary values: 217,344,000
- Estimated download bytes: 925,000,000
- Estimated primary bytes: 869,376,000
- Decode path: curl each pinned .bin from the EIT_rawData/ prefix and check sha256 against SHA256SUMS.txt (which lists 60 EIT .bin files). Check file_size % 4358 == 0. For each 4358-byte frame, little-endian: 2 float32 timestamp, 1 float32 dummy, 1024 float32 pixels (the primary), 2 int32 (MinMax, event marker), 30 int8 event text, 1 int32 timing error, 52 float32 Medibus. Parse with struct.unpack_from('<1024f', buf, off+12) and write the pixel block contiguously as float32 LE. The authors' MATLAB reader (Code/read_binData.m) documents this exact layout. Suggested bounded scope: all 20 *_FEM.bin (76,200 frames, about 332 MB) plus *_PEEP_BH.bin for S01-S08 (136,050 frames, about 593 MB): 28 recordings, about 869 MB primary. Alternative clean scope: FEM only (20 samples, about 312 MB).
- Novelty kind: new_modality
- Novelty evidence: novelty.py --url on the respiratory-heartrate-dataset prefix matches only the same host (physionet_circor_pcg_i16, a phonocardiogram recipe). Terms 'electrical impedance tomography', 'pulmovista', 'respiratory-heartrate' match nothing in recipes, registry, ledger or downstream. - Homogeneity: One study and one device (Dräger PulmoVista 500 with the Dräger EIT Data Analysis Tool export), one reconstruction grid (32x32), one sampling rate (50 Hz), one quantity (relative impedance change, AU). The FEM and PEEP_BH protocols are the same measurement process on the same healthy volunteers. Do not mix in the sibling 80-subject respiratory-dataset (also Dräger, but a different study, with 115-236 MB recordings).
- Risks: (1) Values are the device's reconstructed relative-impedance images, not raw electrode voltages. The authors call them raw EIT data and they are the machine-facing export, but the judge may probe 'derived'. (2) Population is 60 recordings (about 3.1 GB primary), so a bounded subset is required: the subject-ordered PEEP_BH cut may read as arbitrary; FEM-only (20 samples) is the conservative fallback. (3) About 29 of 1024 pixels per frame are zero (outside the thorax mask), which is fine. (4) Human volunteers: emit only pixel values, never subject-info. (5) physionet.org was unreachable from the scout sandbox, so licence evidence is the in-bucket LICENSE.txt (CC BY 4.0 legal text, 14,842 B). (6) Only one version (1.0.0) exists, so pin it.
